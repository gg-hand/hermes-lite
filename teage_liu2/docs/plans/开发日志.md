## 2026-09-08 统一扩展目录树:扩展装载运行期化,branches/ 包消亡

> 用户判定"扩展应统一目录树管理、不进 liu2 源码"为大问题。按 `docs/plans/2026-09-08-统一扩展目录树-设计.md`(用户逐条定案)+ 同名实现计划执行完毕。

**架构变化**
- 新增 `core/extension_loader.py`:manifest.yaml 严格解析(ExtensionSpec)→ 目录扫描(discover_extensions)→ importlib 动态装载(load_python_extension,模块名含 manifest_hash 热重载隔离)→ wire_extensions(create_app 与 /reload 共用:校验声明/合并 stdio 字段/已装未启用统计)
- registry 新增 `set_directory_loader` 目录发现通道(解析优先级:factory > directory_loader > ValueError);`register_factory` 保留并重新定位 = **测试/行为套件/嵌入注入通道**(设计 §2.1,8 处标注点全链路落实)
- `server/app.py` 装配点例外消失:零 branches import、零 register_factory 调用;`/reload` 重扫 extensions_root + 重接 loader
- config 新增 `core.extensions_root`(默认 data2/extensions,仓库外不入库)
- **`teage_liu2/branches/` 整个消亡**:audit / guardrails 外迁为 `data2/extensions/<name>/{manifest.yaml, main.py}`(最小两文件形态,main.py 约定导出 create_branch)
- 文档同步:SPI §12 三步法重写 + §13.2 新章节(manifest 规范/装载语义/信任边界 + register_factory 定位专段)、CORE.md 接入步骤、INTERFACES.md §1/§2/§9 改写

**端到端发现并修复的真实生产缺口**:同语言扩展身份从未向 TransportBus 注册(仅 supervisor 为 stdio 扩展注册)——audit 的 storage_write 在生产路径被"扩展未注册,拒绝入站请求"静默拒绝(audit._write 吞异常仅 warning,落盘全部丢失,2026-08-21 接入验证脚本因手工注册身份而未暴露)。修复:`server/app.py` 新增 `register_inprocess_extension_identities(bus, registry)`,create_app 装配后与 /reload rebuild 后为链上全部普通 Branch 实例注册身份(stdio 扩展仍由 supervisor 负责)。

**取舍**(设计 §8):进程内信任执行(兜底 hook_timeout/异常隔离/L3 超时);guardrails 外迁后安全策略完整性 = 扩展目录完整性(用户定案接受);manifest 规范不入 PROTOCOL v1.0 冻结面。
