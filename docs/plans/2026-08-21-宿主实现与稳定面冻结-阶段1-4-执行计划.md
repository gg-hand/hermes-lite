## 二、全局约束（继承阶段 0 + 本计划特有）

1. **唯一契约源**: `teage_liu2/PROTOCOL/` 是协议唯一契约源。阶段 1-4 的全部实现**对拍 PROTOCOL 域的 schema**，不另造契约；`teage_liu2/docs/CORE.md`、`docs/SUBSYSTEM-SPI.md` 为实现视图（阶段 2 起逐步对齐，阶段 4 强制回写）。
2. **仓库纯净**: 不向仓库写入测试文件（`*Test.py`、`*.test.ts` 等）。行为套件 JSON 黄金用例是协议交付物，已获用户豁免可入库（2026-08-20 确认）；Python 回归测试只允许落在既有 `tests_core/` 既有范围（不新增测试文件时遵循用户最终决定，见边界）。
3. **零新依赖**: StorageWriter / COW 浅拷贝 / transport 编码层均走零新依赖路线（§18.1/§18.2/§18.3）。`pyproject.toml` 现有依赖已确认无 aiosqlite/pyrsistent/msgpack。
4. **命名约束三模式**（协议级，实现时 schema 强制，非法拒绝）: `extension_name` `^[a-z0-9_]+$` / `kind` `^[a-z0-9_.]+$` / `SetExtra` key `^[a-z0-9_]+\.[a-z0-9_.]+$`。
5. **11 钩子 / 6 Action / 7 终止原因 / 9 消息类型（+ event/heartbeat/shutdown）/ done 9 键**: 与 PROTOCOL 各域 schema 逐字一致（阶段 0 已定稿）。
6. **git 写操作**: 本计划不含任何 `git add/commit/push`（提交须用户另行批准）。
7. **Python 入口**: `D:\soft\Python311\python.exe`（`python` 为 Store stub 不可用）。
8. **临时校验脚本**: 放 `d:/tmp/`（仓库外），用完即删，不落盘仓库、不 `git add`。
9. **验证先于断言**: 每任务完成须跑验证命令取新鲜输出，不得凭历史记录断言（对齐 verification-before-completion）。
10. **降级优先**: 可选组件（jsonschema、异语言进程等）缺失时 try/except 降级，主对话不中断（§0）。
