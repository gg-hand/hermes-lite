## 三、执行中的修正记录（完美主义落实）

1. **匹配器歧义修复**: `Matcher` 由 `oneOf` 改为 `anyOf` + 显式解释器优先级（absent → 标量 → 数组 → 对象）——`{regex:...}`/`{range:...}`/`{length:n}` 同时满足 ScalarMatcher 与 ObjectMatcher（后者 additionalProperties 过宽），`oneOf` 报"同时匹配多个"歧义；`anyOf` + 优先级语义消除，且与设计文档 §14.3"所有宿主实现内置同一语义的匹配器解释器"对齐。
2. **用例 `absent` 语义收紧**: `EventExpectation.absent` 仅 `true`（负断言）；删除用例中冗余的 `"absent": false` 正向条目（正断言直接写 type+payload 即可）。
3. **用例校验引用解析**: 用例文件是单个 TestCase，校验须走 suite.schema.json 的 `definitions.TestCase` + referencing Registry 注册跨文件引用（matcher.schema.json），而非顶层结构。
