## 三、执行中的修正记录

1. **值对象兼容层设计**：`Message/Block/Event` 仍保持 `Dict[str, Any]` 类型别名（现有链路零改动）；值对象以「工厂 + 校验函数 + Snapshot dataclass」增量加入，不强切现有数据流。`Snapshot` 仅定义结构与序列化，快照推进/revision 递增逻辑随阶段 2 的 action 应用落地。
2. **校验分层**：`validate_messages`（LLM 前 user/assistant 交替校验，M1 语义）保持不动；新增 `validate_message_shape`（单条消息角色白名单含 tool + content 形态，协议 schema 级）与之分层。
3. **StorageWriter 有界队列丢弃语义**：满队列丢弃最旧时，若被丢弃任务是 flush（带 Future），必须以异常 resolve——调用方 await 会收到错误而非永久挂起（§15-A6 背压可观测信号 = 丢弃计数）。
4. **background 失败重试**：重试 1 次后仍失败 → error 日志（§18.1「失败重试 + error 日志」）。
5. **数据层用例事件通道诚实标注**：`06-storage-spi.json` 的 `custom:storage_result` 观测事件依赖 evolution custom 扩展点（core 透传），该事件通道随阶段 3 transport `storage_*` 消息接线后全量对拍；阶段 1 由 Python 实现冒烟覆盖 SPI 语义（kind 前缀 / query limit / write 批量）。
