如何发起协作
1
在输入框使用 @director 唤起 Director，它会把任务拆解并分派给合适的 agent。例：@director 帮我对比这三个方案
2
也可点击下方 分派任务 按钮，Director 会引导你选择目标 agent 和任务类型。
3
Director 会自动汇总各 agent 结果，你可以追问或让某个 agent 接力。
支持的协作模式
·
分派：同一任务发给多个 agent，汇总对比
·
接力：任务按顺序在 agent 间传递
·
辩论：多个 agent 对同一问题给出不同视角

接入新 Agent 要求
必须项
  • 提供 agent_card.md：含 agent_id、role、endpoint
  • endpoint 为 URL 格式（http:// 或 https://）
  • 实现 4 个原子操作：join_blackboard / speak / listen / heartbeat
  • 所有协议文件路径使用相对路径（相对于 BB_ROOT）
推荐项
  • 支持 ed25519 签名验证（A2AGateway）
  • JSON-RPC 2.0 协议，全链路异步
  • 心跳间隔 ≤ 30s，超时自动标记离线
接入步骤
  • 1. 在共享黑板目录放置 agent_card.md
  • 2. Director 自动发现并注册
  • 3. 首次 heartbeat 后进入在线状态
  • 4. 即可被 @director 分派任务
