Workflow 编排快速上手

三步创建工作流
  1. 选模板：左侧模板库按难度分组，点击卡片一键加载
  2. 配 step：中栏表单填写参数，或切"高级模式"编辑 YAML
  3. 绑定 cron：点"保存为调度"跳转 /scheduler 设置定时
5 种 step 类型
  • deterministic：调用内置模板（directory_watch / email_notify 等）
  • llm：单轮 LLM 调用（prompt + system）
  • tool：直接调用工具（tool + input JSON）
  • react：ReactLoop 多轮工具调用（task + max_loops）
  • subworkflow：嵌套 workflow（P2 stub）
字段说明
  • id：step 唯一标识，用于 depends_on / condition 引用
  • depends_on：前置 step id 列表，所有前置完成后才执行本 step
  • condition：执行条件，如 steps.s1.outputs.count > 0
  • timeout_seconds：step 级超时，为空时用 workflow 级默认
示例：两步流
name: daily_news
steps:
  - id: fetch
    type: tool
    config:
      tool: web_search
      input:
        query: 今日热点新闻
  - id: summarize
    type: llm
    depends_on: [fetch]
    config:
      prompt: 将上一步新闻整理成 300 字简报

保存为调度
